# MesaClick

Proyecto desarrollado para la asignatura **Desarrollo de Aplicaciones Web**.

## Fase 1: Maquetación

En esta primera fase se construirá el esqueleto visual de la aplicación **MesaClick**: solo estructura y presentación (HTML5 y CSS3), todavía sin programación.

### 📋 Requisitos técnicos

1. **Dos páginas enlazadas:**
   - Una página de inicio sobre el tema del proyecto (**MesaClick**).
   - Una página con un formulario maquetado (aún no tiene que funcionar).
2. **HTML5 semántico:**
   - Uso obligatorio de `<header>`, `<nav>`, `<main>`, `<footer>`.
   - Incluir al menos una lista (`<ul>` o `<ol>`), una imagen (`<img>`) y un enlace (`<a>`).
3. **Hoja de estilos externa (`.css`):**
   - Un archivo `.css` enlazado a ambas páginas.
   - Selectores de etiqueta, de clase (`.clase`) y de ID (`#id`).
   - La misma paleta de colores en todo el sitio.

### 🔀 Flujo de trabajo con Git

1. Crear el repositorio del equipo en GitHub o GitLab y agregar al facilitador.
2. Trabajar en la rama `fase-1-maquetacion`.
3. Cada integrante sube sus cambios desde su propia cuenta.
4. Al terminar, unir la rama `fase-1-maquetacion` a `main` mediante **Merge** o **Pull Request**.

```bash
# Cambiar a la rama de trabajo (si aún no estás en ella)
git checkout fase-1-maquetacion

# Guardar y subir cambios
git add .
git commit -m "Descripción de tus cambios"
git push -u origin fase-1-maquetacion
```
